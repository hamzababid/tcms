# Assay logo kit

The mark is an A whose crossbar is a check mark, stamped across it the way an assay office stamps a hallmark on metal that passes. Wordmark: Sora SemiBold, converted to outlines, so no font is needed to display it.

## Files

| Use | File |
| --- | --- |
| Logo on light backgrounds (default) | `assay-logo.svg` |
| Logo on dark backgrounds | `assay-logo-on-dark.svg` |
| Logo on Assay Indigo | `assay-logo-white.svg` |
| One-colour (fax, engraving, stamps) | `assay-logo-mono-black.svg` |
| Stacked (square spaces) | `assay-logo-stacked.svg` |
| Mark only | `assay-mark.svg`, `assay-mark-on-dark.svg`, `assay-mark-mono-indigo.svg`, `assay-mark-mono-black.svg`, `assay-mark-white.svg` |
| Wordmark only | `assay-wordmark.svg` |
| App icon / favicon | `assay-app-icon.svg`, `favicon.svg`, `favicon.ico` (16/32/48) |
| PNG exports | `png/` — app icon 16–1024 px; logos at 64, 128, 256 px tall; mark 256/512 |

All SVGs use a true transparent cut-out between the check and the A, so they work on any background.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Assay Indigo | #4F46E5 | Check, app tile, product accent |
| Ink | #0F172A | A and wordmark on light |
| Soft Indigo | #A5B4FC | Check on dark; A on the app tile |
| Night | #111827 | Dark backgrounds, sidebar |
| White | #FFFFFF | On dark and on Assay Indigo |

## Rules

- Clear space: ⅜ of the mark's height on every side.
- Minimum size: logo 92 px wide (25 mm in print); bare mark 20 px; below that use the app tile (down to 16 px).
- Don't stretch, rotate, recolour, add shadows or effects, or place on low-contrast or busy backgrounds.
